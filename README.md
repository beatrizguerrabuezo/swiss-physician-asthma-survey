# Swiss Physician Asthma Survey

This repository contains the R code used for the statistical analyses of a nationwide Swiss physician survey on diagnostic practices for asthma in school-age children.

## Analysis

The file `analysis_physician_survey.qmd` contains the R/Quarto code used for data management, descriptive analyses, comparisons between physician groups, and regression analyses reported in the manuscript.

## Data availability

Individual-level survey data are not publicly available to protect participant confidentiality.

## Software

Analyses were performed using R.
